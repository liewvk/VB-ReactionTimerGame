# VB Reaction Timer Game

A Visual Basic .NET reaction-timing game based on the "VB Game Programming Chapter 17" project.

## Overview

This project is a simple game where the player tests their reaction speed by waiting for a visual cue and then clicking as quickly as possible. It demonstrates basic game-loop concepts, timing logic, and user input handling in Visual Basic .NET.

## Features

- Reaction timing gameplay
- Visual start/ready state
- Randomized delay before the signal appears
- Score tracking based on speed
- Simple Windows Forms based interface

## Project Type

- Language: Visual Basic .NET
- Platform: Windows desktop application

## Getting Started

1. Open the project in Visual Studio.
2. Restore NuGet packages if required.
3. Build the solution.
4. Run the application from Visual Studio.

## Repository Structure

- `*.sln` – Visual Studio solution files
